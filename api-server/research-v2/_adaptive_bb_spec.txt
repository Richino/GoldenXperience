==================================================
5. WALK-FORWARD ADAPTATION
==================================================

This is critical.

The adaptive engine must behave as if it is experiencing the market sequentially.

For every signal at time T:

1. Calculate the frozen BB+RSI signal using information <= T.
2. Construct its context using information <= T.
3. Adaptive engine may use ONLY outcomes that were already RESOLVED before T.
4. Produce an adaptive decision:

TAKE
or
WAIT

5. Lock that decision.
6. Advance time.
7. Resolve the 10-minute outcome.
8. Only AFTER resolution may that result become evidence for future decisions.

NO signal may learn from itself.

NO future prediction outcome may influence an earlier decision.
