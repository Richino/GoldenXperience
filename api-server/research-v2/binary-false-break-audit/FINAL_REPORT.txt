EVENT DEFINITION
================================

Support: rolling lows 10/20/50, confirmed swing lows k=2, prior session low, prior day low, clustered touches (merge ≤0.1 ATR)
Resistance: mirror highs
Break: penetration ≥ 0.05 ATR beyond pre-existing level (buckets still reported for all depths)
Failed break: penetrates then reclaim candle closes back inside within 3 bars; signal AFTER reclaim close
Held break: break candle closes beyond; next 1 bar(s) also close beyond (no reclaim); signal AFTER confirm close
Entry timing: entry_price = mid close of confirmation candle; expiries from closeMs
Deduplication: episodeKey=instrument|side|levelBucket|30minSlot; first signal only; report raw vs effective n
