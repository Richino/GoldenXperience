================================
WHAT COUNTS AS A STRUGGLE
================================

Final pre-registered definitions:
Zone: cluster of ≥2 confirmed local extremes within 0.2 ATR (also registered widths 0.1/0.2/0.3)
Attempt: confirmed swing high (resistance) or swing low (support), k=2, lookback=90, deduped if <3 bars apart
Progress: successive extreme extension in ATR; slope → DIMINISHING / FLAT / INCREASING
Rejection: max adverse excursion after attempt / ATR; slope → WEAKENING / STABLE / STRENGTHENING
Compression: rolling 20-bar range/ATR + % bars within 0.25 ATR of zone → NONE / MODERATE / STRONG
Failed breakout: last ≤3 completed bars penetrate beyond zone then close back inside
Breakout pressure: attempts≥3 + WEAKENING rejection + MODERATE/STRONG compression + timeNear≥35%
Exhaustion: |prior 20-bar move| ≥ 1.2 ATR into zone + non-increasing progress
Primary states: RESISTANCE/SUPPORT_REJECTION, *_BREAKOUT_PRESSURE, FAILED_*, BUYER/SELLER_EXHAUSTION; else WAIT
